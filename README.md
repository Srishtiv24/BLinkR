# BlinkR - Smart Mock Interview Platform

BlinkR is a next-generation mock interview platform designed to help candidates prepare effectively with real-time collaboration tools and AI-driven question generation.

---

## 🚀 Current Features (v1)

- **Video Calls (WebRTC)**  
  Seamless peer-to-peer video interviews with low latency.

- **Live Chat (Socket.IO)**  
  Real-time messaging during interviews for smooth communication.

- **Screen Sharing (Video + Audio)**  
  Share your screen and audio for coding demos, presentations, or portfolio walkthroughs.

- **Resume Upload**  
  Candidates can upload resumes directly to the platform.

- **AI-Generated Questions from Resume**  
  BlinkR analyzes resumes and generates tailored interview questions to simulate recruiter-style interviews.

---

## 🔮 Future Enhancements (v2)

- **Coder-Friendly Tools**  
  - Integrated **Code Editor/Box** for live coding challenges.  
  - **Rooms** for collaborative coding sessions and group interviews.  
  - **AI Mock Interviewer** that simulates recruiter or technical interviewer behavior with adaptive questioning.

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express  
- **Real-Time Communication:** WebRTC, Socket.IO  
- **Database:** MongoDB  
- **AI :** Resume parsing & question generation pipeline
